## 강조

**굵게**, *기울임*, ***굵은 기울임***, ~~취소선~~, `인라인 코드`를 쓸 수 있어요.
밑줄 문법도 돼요: __굵게__, _기울임_. 하지만 snake_case_name 같은 단어는 그대로 보여요.

줄 끝에 공백 두 칸을 넣으면  
이렇게 줄이 바뀌어요.

\*별표\*를 글자 그대로 쓰고 싶으면 백슬래시를 앞에 붙여요.

## 코드

```javascript
// 테마를 바꾸는 함수
function toggleTheme() {
  const root = document.documentElement;
  const next = root.dataset.theme === 'dark' ? 'light' : 'dark';
  root.dataset.theme = next;
  return next < 'z' && next > 'a'; // <, > 같은 기호도 그대로 보여요
}
```

```
언어 표시 없이 쓴 코드 블록이에요. **이 안은** 마크다운으로 바뀌지 않아요.
```
