# Review — pixel-editor

검증일: 2026-11-25 · 기준: `spec.md` 11절 · 검증자: Review 서브에이전트(Build와 별개)

## 1. 요약

- **통과 44 / 실패 0 / 미검증 3** (총 47항목)
- **최종 판정: 통과.** 고칠 버그는 찾지 못했고, 코드는 수정하지 않았다.
- 검증 방법
  - 코드 리뷰: 전체 파일(`index.html`, `style.css`, `js/*.js` 6개)
  - 로직 테스트: Node에서 `file:///`로 `pixels.js`·`history.js`·`storage.js`를 import해 32개 단언 실행(모두 PASS, 무작위 직선 2000개 연결성 포함)
  - 브라우저 테스트: 내장 브라우저, `http://localhost:8000/apps/pixel-editor/`. 375×812(DPR 2) 모바일 에뮬레이션, 1024×800 데스크톱, 라이트/다크, 310×600 iframe(동적 생성)
- Build 에이전트가 알려 준 내용도 확인했다.
  - `storage.js`가 `validateState(data)`를 추가로 export한다. 맞다(spec 9.5에 없는 추가 export이며 문제는 없다).
  - 359px 미만에서 "전체"와 "배율" 글자를 시각적으로 숨기고 좌우 여백을 8px로 쓴다. 맞다.
  - 4칸마다 진한 격자선을 같은 선을 두 번 그려 만든다. 맞다(4절 참고).
  - 칸 판정에서 1px 테두리를 뺀다. 맞다(`clientLeft`와 `clientWidth` 사용).

| 항목 | 결과 | 근거 |

| 클릭 = 한 칸, 드래그 = 연속 | 통과 | 합성 PointerEvent와 실제 마우스 드래그(`left_click_drag`) 모두 대각선이 끊김 없이 칠해짐 |

| 오른쪽 클릭은 칠하지 않고 메뉴도 없음 | 통과 | button 2는 무시, `contextmenu`는 `defaultPrevented`. 실제 오른쪽 클릭에서도 칠해지지 않음 |

| 전체 지우기, 알림, 되돌리기로 복구 | 통과 | announcer 문구 일치, undo로 복구 |
| 한 획 = 되돌리기 1번, disabled 상태, 변화 없는 클릭은 기록 안 남김 | 통과 | 3획 → undo 3번. 같은 색 클릭 뒤에도 3번. 획 도중 Ctrl+Z는 무시됨. `pointercancel` 뒤에도 칠한 것이 남음 |

## 3. 발견한 문제와 수정 내용

수정한 파일은 없다. 실패 항목이 없고, 아래 4절의 내용은 spec 허용 범위 안이거나 취향에 가까워 고치지 않았다.

## 4. 남은 문제·미검증 항목

- **미검증 3개**
  - 실제 터치 스크롤·확대 방지(11.3-1)
  - 캔버스 밖 터치 스크롤(11.3-3)
  - iframe에서 실제 파일이 내려받아지는지(11.5-4). Embed 단계에서 블로그 iframe의 `sandbox`에 `allow-downloads`가 있는지도 함께 확인해야 한다.
- **(권장) 310×600 카드 배치**
  - spec 2.3의 예상 높이는 588px인데 실제는 654px이다. 작업 줄이 `[격자][지우기][배율 select]` / `[PNG 저장]` 두 줄로 나뉘기 때문이다(select가 115px).
  - 주 동작인 저장 버튼이 첫 화면 아래로 약 38px 밀려 스크롤해야 보인다. spec이 세로 스크롤을 허용하므로 실패로 보지 않았다.
  - 줄이려면 좁은 화면에서 옵션 글자를 줄이거나(`16×`) 저장 버튼 글자를 "저장"으로 줄이는 방법이 있다.
- **(경미) 진한 격자선**
  - 같은 선을 두 번 겹쳐 그리면 실제 불투명도가 1-(1-a)²이 된다(라이트 0.33). spec은 `globalAlpha` 2배(0.36)를 정했다.
  - 눈으로는 구분되므로 그대로 두었다.
- **(경미) DPR만 바뀔 때**
  - 창을 다른 배율의 모니터로 옮겨 CSS 크기는 그대로이고 DPR만 바뀌면 `ResizeObserver`가 반응하지 않는다. 그래서 내부 해상도를 다시 맞추지 않는다(`image-rendering: pixelated`라 흐려지지는 않음).
- **참고**: 검증하면서 이 브라우저 프로필의 `pixel-editor:v1` 저장값을 지웠다(테스트 시작과 끝에 모두 지움).
